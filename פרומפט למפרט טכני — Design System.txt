# 📐 מפרט טכני — Design System מלא (ללא שמות קבצים)

מסמך זה מתאר את שכבת העיצוב, ה-UX והוויזואליה של הפרויקט — ברמת פירוט שמספיקה כדי לשחזר את השפה העיצובית בפרויקט אחר. אין כאן שמות קבצים, נתיבים או מזהים פנימיים — רק עקרונות, טוקנים, קומפוננטות ותבניות.

---

## 1. שפת עיצוב — עקרונות על

| עיקרון | יישום |
|---|---|
| **Mobile-first Telegram** | כל מסך בנוי לרוחב 360–420px, ללא גלילה אופקית של הדף. `max-width: 600px` על מודאלים. |
| **RTL מוחלט** | כל הממשק `dir="rtl"`. כותרות, רשימות, אייקונים וכרטיסים מימין לשמאל. מודאלים עבריים מחייבים `dir="rtl"` גם אם האב LTR. |
| **Dark-first** | רקע כהה מאוד, כרטיסים בגוון כהה-אפרפר, טקסט לבן/אפור-בהיר, מבטאים בצבעים רוויים. |
| **Fintech Premium** | תחושת Stripe/Brex/Revolut: כרטיסים קטנים עם KPI, גרדיאנטים עדינים, גבולות דקורטיביים שקופים, פינות מעוגלות. |
| **Progressive disclosure** | מסך ראשי → מודול → מודאל מפורט. אין מסך אחד עמוס. |
| **Feedback מיידי** | כל פעולה מציגה toast / שינוי צבע / ספינר. אין "לחיצה שקטה". |

## 2. טוקנים — צבעים

--error:          #ff6b6b;   /* הפסד, שגיאה */

/* גבולות */

--border-medium:  rgba(255,255,255,0.10);

**כלל שימוש בצבעים:**

- כחול — CTA ראשי וקישורים.
- צהוב — אזהרה בלבד.
- כל צבע מבטא חייב להופיע גם כרקע-שקוף עדין (`0.10–0.20`) בגבולות ובכרטיסים.

## 5. שלד המסך — Layout גלובלי

### 5.1 שלד
```
┌────────────────────────────┐
│  App Header (sticky, 56px) │   ← לוגו + שם משתמש + גלגלת התראות
├────────────────────────────┤
│                            │
│   Screen Content           │   ← padding: 16px, scroll-y
│   (scrollable)             │
│                            │
├────────────────────────────┤
│  Tab Bar (fixed, 64px)     │   ← 5–9 טאבים, RTL, אייקון+תווית
└────────────────────────────┘
```

### 5.2 Tab Bar — חוקים
- גלילה אופקית כשמעל 5 טאבים.
- **Mask gradient** בקצוות (`mask-image: linear-gradient(to left, transparent, black 8%, black 92%, transparent)`) — fade עדין.
- **גלגלת עכבר אופקית** פעילה גם בדסקטופ.
- **סקרולבר דק** (`scrollbar-width: thin; scrollbar-color: rgba(255,255,255,0.15) transparent`).
- טאב פעיל: אייקון בצבע accent + תווית מודגשת + קו תחתון דק (2px) בגרדיאנט accent.
- טאב לא פעיל: `--hint-color`, opacity 0.7.

### 5.3 App Header
- Sticky top, `backdrop-filter: blur(12px)`, רקע `rgba(11,15,23,0.85)`.
- מימין (RTL): לוגו/אווטאר + שם.
- משמאל: כפתור התראות (FAB קטן עם badge אדום למספר).

## 6. ספריית קומפוננטות

### 6.1 כרטיס בסיסי (Card)
```
┌─────────────────────────────┐
│  כותרת (H3, 15px, 800)      │
│  ─────────────────          │
│  תוכן...                    │
└─────────────────────────────┘
```
- רקע: `--bg-elevated`, פינות `--radius-lg`, גבול `--border-subtle`, padding 16px.
- **וריאנטים:**
  - `hero` — גרדיאנט כהה + גבול accent צבעוני 1px.
  - `accent` — גרדיאנט סגול→כחול עדין + גבול סגול.
  - `warning` — גבול צהוב שקוף.
  - `danger` — גבול אדום שקוף.

### 6.2 KPI Card (כרטיס מדד)
- **רשת 2×2** (לא 4 בשורה אחת — נקרא טוב יותר במובייל).
- מבנה: `ערך גדול (18–24px, 900)` מעל `תווית קטנה (10–11px, hint)`.
- כל KPI יכול לקבל צבע accent שונה (ירוק ל-TVL, כחול למשתמשים, סגול לעמלות, צהוב להתראות).
- פינות `--radius-md`, padding 12px, `text-align: center`.

### 6.3 Fintech Grid (רשת מודולים)
```css
display: grid;
grid-template-columns: repeat(auto-fill, minmax(140px, 1fr));
gap: 12px;
```
- כל אריח: כרטיס עם:
  - אייקון/אמוג'י גדול (24–28px) בפינה.
  - כותרת מודול (14px, 700).
  - שורת KPI אחת ("3 משתמשים", "TVL $100").
  - חץ עדין שמאלה (RTL) לסימון "נפתח במודאל".
- Hover: `transform: translateY(-2px)`, `box-shadow` מוגבר.
- Active (tap): `scale(0.98)` ל-120ms.

### 6.4 Module Row (שורה במודאל מודול)
```
┌──────────────────────────────────────┐
│  👤  Manuel                $6,161.00 │
│      UID 6039338998 · admin          │
└──────────────────────────────────────┘
```
- גובה 56–64px, padding אופקי 12px.
- צד ימין (RTL): אייקון/אווטאר + כותרת + תת-כותרת.
- צד שמאל: ערך/סטטוס/כפתור.
- גבול תחתון `--border-subtle`.
- שורה אחרונה — ללא גבול.

### 6.5 כפתורים

| סוג | רקע | טקסט | שימוש |
|---|---|---|---|

| Secondary | `--purple` | לבן | Wizard, Admin |

| Danger | `--error` | לבן | מחיקה, יציאה |
| Success | `--success` | לבן | אישור, אישור הפקדה |

- גובה 40–44px, פינות `--radius-md`, padding אופקי 16px.
- `transition: transform 120ms, background 200ms`.
- **אסור** יותר מ-1 Primary בכל אזור.

### 6.6 Chips / Filter Buttons
```
[ הכל ] [ עסקאות ] [ קרנות ] [ כספת ] [ פיקדונות ]
```
- Pill shape, גובה 32px.
- לא פעיל: רקע שקוף + גבול `--border-subtle` + טקסט hint.
- פעיל: רקע accent שקוף + טקסט accent + גבול accent.
- גלילה אופקית עם mask gradient בקצוות.

### 6.7 Badge (תגית סטטוס)
- Pill, 11px, 700, padding 4px 8px.
- וריאנטים: `live` (ירוק), `demo` (כחול), `warning` (צהוב), `danger` (אדום), `admin` (סגול).
- דוגמאות: 🟢 פתוח, 🔒 נעול, ⏳ ממתין, 🟣 אדמין.

### 6.8 Feed Item (פריט פיד)

│ (M) Manuel · 🛒 קנייה · לפני 3 דק׳   │
│ קניתי 312 TON ב-$1.60 (בדמו)         │

│ 💬 תמכור מהר   ❤️  👍  📋  💡       │

- שורת מטא: שם + badge סוג פעולה + זמן יחסי.
- גוף: תוכן.
- טיפ (אופציונלי): בלוק עם רקע accent עדין.
- שורת פעולות: אייקונים קטנים עם תוויות.

### 6.10 Progress Bar

### 6.11 Chart (גרף)

- ללא legend (המידע בכרטיס).

### 6.12 FAB (כפתור צף) — התראות
- עגול 52px, `position: fixed; bottom: 80px; left: 16px` (RTL — שמאל, מעל ה-Tab Bar).
- רקע accent, צל חזק, badge אדום קטן עם מספר.
- `active: scale(0.94)`.

## 7. מערכת מודאלים — חוקי ברזל עיצוביים

### 7.1 מודאל Full Screen
```
┌────────────────────────────┐
│ ← חזרה           כותרת     │  ← Header 56px, sticky
├────────────────────────────┤
│                            │
│   תוכן (scrollable)        │
│                            │
├────────────────────────────┤
│ [ ביטול ]   [ אישור ]      │  ← Footer 64px, sticky
└────────────────────────────┘
```
- `max-width: 600px; margin: 0 auto`.
- `position: fixed; inset: 0; z-index: 9999`.
- **חייב להיות מחוץ לכל container עם `transform`/`overflow`** (אחרת `position: fixed` נשבר).
- פתיחה: `active` class → `opacity 0→1`, `transform: translateY(12px)→0`, 200ms.
- סגירה: אותה אנימציה הפוכה, 180ms, ואז `display: none`.

### 7.2 מודאל מודול (Admin Module)
- Header: שם מודול + אייקון + כפתור סגירה.
- גוף: KPI grid למעלה → רשימת שורות → כפתורי פעולה בתחתית.
- Footer: כפתור Primary אחד בלבד ("פעולה ראשית") + Ghost ("סגור").

### 7.3 כללי מודאל (אסור להפר)
1. מודאל חייב להיות מחוץ לכל `screen-*` — אחרת ה-`fixed` נשבר כשיש `transform` על parent.
2. אין `hidden` על מודאל — רק `.active` (פתוח) או כלום (סגור).
3. `aria-modal="true"`, `role="dialog"`.
4. תמיד `dir="rtl"` על מודאל עברי — גם אם האב LTR.
5. Escape סוגר, לחיצה על overlay סוגרת, כפתור X תמיד בפינה.

## 11. RTL — חוקים ספציפיים

1. `dir="rtl"` על `<html>`.
2. `text-align: right` כברירת מחדל, `text-align: left` רק למספרים בטבלה ולקוד.
3. כפתור "חזרה" במודאל — חץ **ימני** (→) בצד ימין.
4. אייקונים סמנטיים (חץ "הבא") מתהפכים אוטומטית; אייקונים אוניברסאליים (❤️, 📊) לא.
5. `margin-left/right` → להחליף ל-`margin-inline-start/end` בכל הקוד החדש.
6. `padding-left/right` → `padding-inline-start/end`.
7. `float` — להימנע; להשתמש ב-flex/grid עם `dir="rtl"`.
8. גרפים (Chart.js) — ציר X מתהפך אוטומטית ב-RTL; לוודא `rtl: true` ב-options.

## 13. נגישות

- ניגודיות מינימלית 4.5:1 לטקסט רגיל, 3:1 לטקסט גדול.
- כל כפתור אייקון — `aria-label` בעברית.
- פוקוס גלוי: `outline: 2px solid var(--purple); outline-offset: 2px`.
- טופס: `<label>` מקושר ל-`<input>`, לא placeholder בלבד.
- מודאל: focus trap + Escape.
- לא לסמוך על צבע בלבד — תמיד להוסיף אייקון/טקסט (▲▼ ליד אחוזים).

## 15. חוקי ברזל עיצוביים (Design Do's & Don'ts)

### ✅ חובה
1. כל מודאל מחוץ לכל container עם `transform`/`overflow`.
2. `max-width: 600px` על מודאל.
3. KPI cards — **2×2**, לא 4 בשורה.
4. כפתור Primary אחד בלבד לכל אזור.
5. כל טופס עם `<label>` גלוי — לא placeholder בלבד.
6. כל פעולה מציגה feedback תוך 100ms.
7. כל כרטיס עם padding 12–16px, פינות 8–20px.
8. מספרים עם `tabular-nums`.
9. גרדיאנטים רק על hero/accent cards — לא על כל כרטיס.
10. fade mask בקצוות של כל גלילה אופקית.

### ❌ אסור
1. יותר מ-2 משקלי גופן באותו כרטיס.
2. יותר מ-2 צבעי accent באותו מסך.
3. `!important` ב-CSS.
4. אנימציה על `width/height/top/left`.
5. מודאל בתוך `screen-*`.
6. `hidden` על מודאל — רק `.active`.
7. כפתור בלי תווית (רק אייקון) — חייב `aria-label`.
8. טבלה ללא `tabular-nums`.
9. `overflow: hidden` על container שמכיל מודאל.
10. placeholder במקום label.

## 16. Design Checklist לפרויקט חדש (העתק-הדבק)

לפני שמגדירים "העיצוב מוכן":

- [ ] טוקנים מוגדרים ב-`:root` (צבעים, מרווחים, פינות, צללים).

- [ ] שלד: Header sticky + Content scroll + Tab Bar fixed.
- [ ] Tab Bar עם mask gradient וגלילה אופקית.
- [ ] ספריית קומפוננטות: Card (4 וריאנטים), KPI, Chip, Badge, Button (5 סוגים), Modal.
- [ ] כל מודאל מחוץ ל-`screen-*`, `max-width: 600px`, `.active` בלבד.

- [ ] Toast גלובלי.
- [ ] KPI 2×2 במובייל.
- [ ] Feed items + Badges grid.
- [ ] Chart.js עם צבעי טוקנים.

- [ ] אנימציות רק על transform/opacity.
